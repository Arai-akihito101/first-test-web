# 育苗シート工房 - 小さな収益化の自動化実験

`first-test-web` のトップページから `/garden-label/` にリダイレクトする静的アプリ。

## できること
- 苗ラベルをA4用紙に1〜240枚出力（3種類のレイアウト）
- 複数の植物・品種と必要枚数を1行ずつ入力し、一括印刷（合計240枚まで）
- 播種トレー配置図を1〜12行 × 1〜12列で生成
- 画面の「印刷・PDFで保存」ボタンからブラウザの印刷機能を呼び出す
- ログイン不要・外部API不要・端末内処理。利用者が入力した情報の送信・保存なし

## 開発と公開
- GitHub Pull Request経由で確認、マージ後にCloudflare PagesのGit連携で公開
- `node --test tests/logic.test.mjs` で純粋関数を自動テスト
- `.github/workflows/garden-label-test.yml` でPR時のテスト

## 収益化（契約と本人確認は手動）
1. アプリ公開後、A8.net等のASPに自分で登録し、サイトを登録。
2. 園芸用品の適切な広告案件の提携承認を受ける。
3. 広告プログラムが許可する紹介リンクを `garden-label/affiliate.js` の `affiliateLinks` に設定する。`https://` で始まるURLのみ。
4. PRで確認してマージすると「広告・PR」のラベル付きでリンクが表示される。
5. 有効な広告リンクが空欄の間、広告欄は表示されず、収益も生まれない。

**注意**：アフィリエイトの売上発生や報酬受取は保証されない。販売者・サイト運営者としての各種の義務は残る。実際の承認・売上・支払いの確認はASPの管理画面で行う。自分で成果条件のない申し込みをして報酬を作り出す行為は禁止。

## 個人情報・安全
フォームへの入力内容はブラウザ上のDOMのみで使い、localStorage・外部送信を行いません。ホスティングやASP側のアクセスログ・広告遷移時の取り扱いは別です。認証キー・口座情報はGitHubに保存しないでください。
